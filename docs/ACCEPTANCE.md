# 各批次驗收清單（Batch 0–15）

> 這是開發過程中各批次的手動驗收步驟，供在真實裝置上逐項確認。產品說明請見 [README.md](../README.md)，部署請見 [DEPLOY.md](../DEPLOY.md)，測試報告請見 [QA.md](../QA.md)。

依《商用級產品設計與開發規格書 v1.0》分批開發。目前完成 **Batch 0–15（含補齊）**。

## 執行
直接雙擊 `index.html` 即可（目前為純靜態、無 ES module）。
Batch 2 加入 Service Worker 後須用 HTTP 伺服器：`python3 -m http.server 8080` → http://localhost:8080

## 架構原則
- `js/state.js`：唯一 Navigation State + Logger，全站共用。
- `js/providers.js`：Provider 介面契約（location/map/routing/search/traffic/weather/parking/ai）。
- `js/demo.js`：Demo Provider，一律標示 DEMO，未實作即回報 NOT_IMPLEMENTED，不假造資料。
- 資料服務狀態由「網路」＋「資料包」推導：ONLINE / OFFLINE / DOWNLOADING / UPDATING / DEGRADED。
- 全部使用相對路徑；其餘模組（router、routing 等）在各自批次建立。

## Batch 13：媒體／電話／通知（抽象層）
規格明定這三項「依瀏覽器、作業系統與裝置能力決定」，因此以 Provider 抽象層實作，並在畫面上據實說明限制（導航頁「媒體與通知」面板最下方列出此裝置的能力）：
- **音樂**（`media` Provider）：只能播放**本頁**的音訊——你選的本機音訊檔，或 Demo 合成音軌；**無法控制其他 App 的音樂**。導航畫面右側有浮動控制列（上一首／播放暫停／下一首）。導航語音說話時音樂自動降低音量；關閉導航語音**不影響**音樂；接聽（模擬）來電時暫停、掛斷後恢復。
- **電話**（`phone` Provider）：網頁**無法偵測或接聽真實來電**。撥號只能開啟系統的 `tel:` 連結由電話 App 處理；**行駛中不可輸入號碼**（110／119／112／911／999 例外）。「模擬來電」純為 DEMO，用來驗證畫面不遮蔽導航資訊。
- **通知**（`notifications` Provider）：策略引擎——行駛中（> 5 km/h）一般通知只顯示一行標題、沒有操作；低優先通知存入「通知匣」；接近轉彎（≤ 100 m）時非緊急通知一律延後；緊急通知（來電）仍顯示但只給單鍵操作；同一則 30 秒內不重複、顯示間隔至少 8 秒；停車後（且不在轉彎前）整理成一則「有 N 則未讀通知」摘要。頁面在背景且已授權時，緊急／一般通知會改走系統通知（`Notification`，依裝置而定）。
- **不遮蔽導航核心資訊**：浮動元件固定在右側中段；`overlay.js` 每 0.8 秒檢查，若與轉彎橫幅、底部資訊列、車速、車道、警示、改道卡片等重疊，先縮成精簡版，仍重疊則隱藏（來電永不隱藏，只縮到最小並記錄警告）。
- AI 助理新增「播放音樂／暫停音樂／下一首／上一首」。
- 驗收：
  - [ ] 「媒體與通知」→「音樂」：播放 Demo 合成音，浮動列出現在右側；選本機音訊檔可播放；開始導航後語音說話時音量降低
  - [ ] 「電話」→「模擬來電」：右側出現來電橫幅（不蓋住轉彎提示與底部資訊）；接聽後音樂暫停、掛斷後恢復；30 秒不接變成「未接來電」通知
  - [ ] 開始導航並行駛中：撥號欄停用並提示「行駛中無法輸入號碼」；停下來（暫停 Demo GPS）後可輸入
  - [ ] 「通知」→ 模擬一般／低優先／緊急：行駛中一般通知只出現一行、低優先進通知匣、接近轉彎時一般通知不出現；停車後出現摘要
  - [ ] 縮小視窗或開啟多個面板時，浮動元件不會蓋住轉彎橫幅與底部資訊列（會自動縮小或隱藏）
